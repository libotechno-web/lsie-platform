# المنصة الوطنية للابتكار وريادة الأعمال
## الجمعية الليبية للابتكار وريادة الأعمال (L.S.I.E)
**Libyan Society for Innovation & Entrepreneurship**

منصة رقمية وطنية متكاملة صُممت لتكون المظلة الجامعة للمبتكرين، رواد الأعمال، أصحاب الشركات الناشئة، المستثمرين، والموجهين في دولة ليبيا، وتوفير بيئة رقمية حاضنة تدعم تحويل الأفكار الإبداعية إلى مشاريع اقتصادية ناجحة ومستدامة.

---

### 1. السند القانوني والاعتمادات الرسمية
- **المؤسسة المشرفة:** الهيئة الليبية للبحث العلمي - وزارة التعليم العالي والبحث العلمي (دولة ليبيا).
- **قرار الإشهار:** قرار إشهار رقم (525) لسنة 2026م استناداً إلى القرار التنظيمي رقم (1714) لسنة 2025م.
- **شهادة مزاولة النشاط العلمي:** رقم `LARS-SCS-2026-042` الصادرة بتاريخ 15 / 06 / 2026م.
- **المقر الرئيسي المعتمد:** جامعة غريان - غريان، ليبيا.

### 2. البنية البرمجية والتقنيات المستخدمة
- **الخادم الخلفي (Backend):** 
  - Python 3.12
  - Flask كإطار عمل رئيسي بتصميم وحدات برمجية مستقلة (Flask Blueprints).
  - SQLAlchemy 2.0 لإدارة الوصول الآمن للبيانات ودعم العلاقات وقواعد البيانات المتعددة.
  - Flask-Login لإدارة الجلسات وصلاحيات تسجيل الدخول الآمن.
  - Flask-WTF و WTForms لحماية النماذج ومنع ثغرات CSRF والتحقق من صحة المدخلات.
- **قواعد البيانات (Database):**
  - **SQLite** مع تفعيل قيود المفاتيح الخارجية عبر PRAGMA في بيئة التشغيل القياسية (محفوظة في `data/lsie.db`).
  - **جاهزية الانتقال إلى PostgreSQL:** البنية مطابقة لمعايير ORM العالمية، ويكفي تغيير متغير `DATABASE_URL` إلى رابط PostgreSQL للانتقال الفوري دون تغيير أي سطر برمجي في التطبيق.
- **الواجهة الأمامية (Frontend):**
  - HTML5 & CSS3 متجاوب بالكامل مع نهج **Mobile-First**.
  - إطار العمل **Bootstrap 5.3 RTL** المعتمد مع أيقونات Bootstrap و FontAwesome.
  - خط **Cairo** العربي المتناسق والأنيق.
  - مكتبة **Chart.js** لعرض الرسوم البيانية الإحصائية الحية المشتقة من استعلامات قاعدة البيانات.
- **الأمان والخصوصية (Security & RBAC):**
  - تطبيق نظام صارم للأدوار والصلاحيات (Role-Based Access Control) على مستوى الخادم باستخدام Decorators (`@role_required`, `@admin_required`, `@reviewer_required`).
  - تشفير كلمات المرور باستخدام خوارزميات التجزئة الآمنة `Werkzeug Security`.
  - التحقق من امتدادات الملفات المرفوعة ومنع تنفيذها أو رفع ملفات ضارة.
  - حماية الأفكار غير المنشورة وحجب الملاحظات الداخلية والتقييمات السرية عن المتقدمين.

### 3. المعمارية الموجهة بالبيانات (Data-Driven Architecture)
كافة محتويات المنصة قابلة للإدارة والتعديل من لوحة التحكم الشاملة دون الحاجة لتعديل ملفات HTML أو Python:
1. **الهوية والألوان:** الشعار، اللون الأساسي (Primary)، اللون الثانوي (Secondary)، ولون التمييز (Accent) تُدار وتُحقن في قوالب CSS تلقائياً.
2. **النبذة والرسالة والرؤية:** النصوص الرسمية المعتمدة قابلة للتحديث وفق البيانات الرسمية.
3. **الصفحات والقوائم:** نظام إدارة محتوى (CMS) لإنشاء صفحات جديدة وتخصيص عناصر القائمة العلوية والتذييل وترتيبها.
4. **الفرص والمنح والتدريب:** إمكانية إضافة وحذف وتعديل فرص التمويل والدورات التدريبية وإدارة المتقدمين.
5. **الربط والشبكات الاجتماعية:** إدارة روابط فيسبوك، إنستغرام، إكس (تويتر)، ولينكد إن من الواجهة مع الإخفاء التلقائي عند عدم التعيين.

### 5. خطوات التثبيت والتشغيل

#### المتطلبات الأساسية:
- تثبيت Python 3.10 أو أحدث.
- أداة `pip` لإدارة حزم بايثون.

#### الخطوة 1: تثبيت الحزم المطلوبة
افتح الطرفية (Terminal / Command Prompt) في مجلد المشروع ونفّذ:
```bash
pip install -r requirements.txt
```

#### الخطوة 2: تهيئة ملف البيئة (.env)
انسخ ملف `.env.example` إلى `.env`:
```bash
copy .env.example .env
```
*(يمكنك تعديل `SECRET_KEY` أو ترك القيم الافتراضية لبيئة التطوير المحلي)*

#### الخطوة 3: تهيئة قاعدة البيانات وإنشاء السجلات الرسمية
قم بتشغيل سكريبت التهيئة لإنشاء الجداول وحقن بيانات الجمعية الرسمية:
```bash
python seed.py
```
*سيقوم السكريبت تلقائياً بإنشاء حساب المدير الافتراضي التالي:*
- **البريد الإلكتروني:** `admin@lsie.ly`
- **كلمة المرور:** `Admin@LSIE2026!`
*(يُنصح بتغيير كلمة المرور فور أول تسجيل دخول من لوحة الإدارة أو الملف الشخصي)*

#### الخطوة 4: (اختياري) إنشاء حساب مدير مخصص عبر الطرفية
يمكنك إنشاء حساب مدير جديد ببيانات مخصصة في أي وقت عبر الأمر التفاعلي:
```bash
flask --app run.py create-admin
```

#### الخطوة 5: تشغيل المنصة
شغّل خادم التطبيق المحلي:
```bash
python run.py
```
ثم افتح متصفحك وتوجه إلى الرابط:
```
http://127.0.0.1:5000/
```

### 7. النسخ الاحتياطي واستعادة البيانات

#### النسخ الاحتياطي الفوري من لوحة التحكم:
1. توجّه إلى لوحة الإدارة > **النسخ الاحتياطي والاستعادة** (`/admin/backups`).
2. انقر على زر **"إنشاء نسخة احتياطية فورية الآن"**.
3. سيتم إنشاء نسخة مختومة بالتاريخ والوقت في مجلد `data/backups/` مع إمكانية تنزيلها بنقرة واحدة.

#### الاستعادة:
- في حال الرغبة في استعادة نسخة سابقة، أوقف التطبيق واستبدل ملف `data/lsie.db` بنسخة ملف الباك اب المطلوب، ثم أعد تشغيل التطبيق.

#### الانتقال إلى PostgreSQL في بيئة الإنتاج:
1. أنشئ قاعدة بيانات فارغة في خادم PostgreSQL (مثال: `lsie_db`).
2. عدّل المتغير في ملف `.env`:
   ```env
   DATABASE_URL=postgresql://username:password@localhost:5432/lsie_db
   ```
3. شغّل أمر التهيئة:
   ```bash
   python seed.py
   ```
   سيتم بناء كافة الجداول والعلاقات والفهارس داخل PostgreSQL فورياً دون أي تعديل في كود المنصة.
